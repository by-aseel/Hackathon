# Demo script

Adapt this outline to the organizers' presentation time limit.

## Three-minute outline

1. **0:00–0:30 — Problem:** who the user is and what they struggle with.
2. **0:30–0:50 — Solution:** explain the outcome in one sentence.
3. **0:50–2:10 — Live demo:** show one complete user journey with prepared data.
4. **2:10–2:40 — Value:** describe the result and the evidence you have.
5. **2:40–3:00 — Close:** explain the current limitation and next useful step.

## Fallback

If network access or an external API fails, use a local demo mode with sample
data and label it clearly. If the application cannot run, show the recorded
journey and describe which parts were verified.

Do not show API keys, personal data, or unrelated browser tabs during the demo.
