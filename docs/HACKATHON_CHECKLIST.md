# Hackathon checklist — October 3, 2026

## Before the event

- [ ] Confirm location, start time, deadline, and judging criteria.
- [ ] Confirm rules about starter code, AI tools, and external APIs.
- [ ] Choose the idea and stack with Dr. Ammar.
- [ ] Check GitHub login and push access on this laptop.
- [ ] Add teammates through GitHub's repository settings if needed.
- [ ] Install the chosen stack's dependencies and verify a local start.
- [ ] Keep required API keys locally and check service quotas.
- [ ] Bring charger, internet backup, and any presentation adapters.

## First 30–45 minutes

- [ ] Fill in the project brief and agree on one core journey.
- [ ] Divide work and assign owners.
- [ ] Create issues for the first working slice.
- [ ] Decide how the application will be demoed or deployed.
- [ ] Get the smallest runnable application onto `main`.

## Build

- [ ] Deliver the core journey before optional features.
- [ ] Integrate frequently and verify on another teammate's machine.
- [ ] Add realistic demo data and understandable failure states.
- [ ] Update the README with exact install, run, and test commands.
- [ ] Add application tests / build checks to CI when the stack is chosen.
- [ ] Save screenshots or a short video as a fallback.

## Last 45–60 minutes

- [ ] Freeze optional features and fix blockers.
- [ ] Run application checks and repository checks.
- [ ] Verify repository and demo access from a fresh session.
- [ ] Rehearse the demo within the organizers' time limit.
- [ ] Confirm attribution, license, and visibility requirements.
- [ ] Submit the requested links before the deadline.
- [ ] Push the final commit and optionally tag it `submission`.
