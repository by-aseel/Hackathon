# Hackathon with Dr. Ammar

Workspace prepared for **Saturday, October 3, 2026** (Asia/Beirut).

## Start here

1. Agree on the problem, target user, and one demonstrable outcome with Dr. Ammar.
2. Fill in [the project brief](docs/PROJECT_BRIEF.md) and choose the stack.
3. Run `powershell -NoProfile -File scripts/check.ps1` to check this workspace.
4. Follow [the hackathon checklist](docs/HACKATHON_CHECKLIST.md).
5. Build one complete user journey and rehearse [the demo](docs/DEMO.md).

This starter is stack-neutral. Application code, dependencies, run commands,
and application tests will be added after the project idea is chosen.

## Working together

Use `main` as the runnable integration branch. Create short feature branches,
commit small changes, and merge frequently. See [CONTRIBUTING.md](CONTRIBUTING.md).

Keep real API keys in a local `.env` file. Start from `.env.example`; only
placeholder values belong in that example. Never commit keys or private data.

Before submission, replace this starter's project decisions with the actual
idea, install/run instructions, screenshots, and a link to the live demo.
